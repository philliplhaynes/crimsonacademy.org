Crimson · group home page

Six mockups, two structures.

All six replace content/crimson-tree-gold.html, keep the tree, and link out to the live sites. They split into two families: the first three treat the tree as three organisations; the second three map all five leaves to individual schools. Click any card to open it full size, then resize the window to see it respond.

All three entities are linked in all six mockups. The Academy goes to crimsonacademy.org and the Foundation to crimsonfoundation.org. Investments goes to a new public overview page, investments.html, which links through to the ops console at crimsontradeswarm.fly.dev — so a parent or donor clicking “Crimson Investments” gets an explanation first rather than landing straight on a trading dashboard. The footers still link the console directly.

That overview page makes no factual claims about strategy, results, or assets, and carries a not-an-offer / not-advice notice. It has a visible “copy still needed” block listing what only you can supply: legal entity and jurisdiction, regulatory status, who manages the capital, and how returns relate to Foundation funding.

Three organisations

Canopy / Trunk / Roots

The tree reads as the group: the whole canopy is “Crimson Academy”, the trunk is Investments, the roots are the Foundation. Three destinations. Simplest story, and it does not change if campuses are added or dropped.

What all six fix

The current page is a splash gate. These are home pages.

 crimson-tree-gold.htmlAll six mockups
Touch devices Broken — everything is behind :hover, which phones do not have All content reachable without hovering
Keyboard Unreachable — hotspots are <img> with click handlers Real links and buttons, visible focus rings
Screen readers No headings, no labels, no landmarks Proper h1/h2, labelled controls, alt text
Search engines Almost no indexable text, no meta description Full copy, title, and description
Scrolling overflow:hidden — one screen, no content Real page that scrolls, with a footer and a sitemap
Motion Embers run forever, ignores prefers-reduced-motion Honours reduced motion; pauses in hidden tabs
Weight 244 KB, tree base64-encoded twice 12–19 KB HTML + one shared 86 KB PNG
Dead links Every href is # Zero. Real URLs, or a visible “link to come”

If you want my pick

Set B is the one that matches how Crimson is actually organised, so I would choose from 04–06 unless the extra campuses are far enough off that showing five schools would overpromise. Within Set B: Constellation if this is a front door people pass through once, Ledger if it has to carry information and grow, Herbarium if you want the structure understood in a single glance.

Whichever you pick, investments.html ships with it — it is the public face of the trunk, shared by all six.
